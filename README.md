# The Finance Library
This project focuses on applying financial theory through data-driven Python tools.

It covers portfolio performance analysis, risk metrics, Monte Carlo simulations, CAPM-based expected returns and Markowitz optimization, with an emphasis on clarity, 
modularity and financial intuition rather than black-box implementations.

Features:
- Financial data retrieval (prices, returns, benchmarks)
- Performance analysis (returns, volatility, Sharpe ratio)
- Risk modeling (beta, VaR, CVaR)
- Monte Carlo simulations for portfolio projections
- CAPM expected return estimation
- Markowitz mean-variance portfolio optimization
- Modular and reusable Python architecture
